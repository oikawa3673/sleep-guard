# スリープ防止ツール v1.0.0

PCが勝手に**スリープ・画面OFF・スクリーンセーバー(自動ロック)**になるのを、**ONの間だけ**抑止する常駐アプリ。
Claude Code などにPC操作をさせている途中で止まる／デモ中に画面が消えるのを防ぐのが目的。

- **本体＝直下 `スリープ防止.exe`**（9.5KB・単体で動く。追加ランタイム不要）
- **他PCへの配布＝直下 `スリープ防止ツール_配布用.zip`**（7.3KB）
- 配布物の中身は `_配布用/`、ソースと旧版は `_作業ファイル/`

## 使い方

1. `スリープ防止.exe` を起動（インストール済みならデスクトップの「スリープ防止」）
2. **「ON にする」** をクリック → 緑の **ON** になれば抑止中（経過時間を表示）
3. 終わったら **「OFF にする」** か、ウィンドウを閉じる（閉じれば自動解除）

- 最小化で**タスクトレイ**へ格納。ダブルクリックで再表示、右クリックでON/OFF切替・終了
- トレイアイコンの色: 灰色=OFF / 緑=ON
- 二重起動しない（もう一度起動すると既存ウィンドウが前面に出る）

## 他のPCへインストール

`スリープ防止ツール_配布用.zip` を渡し、展開して **`インストール.bat` をダブルクリック**するだけ。

- **管理者権限は不要**（`%LOCALAPPDATA%\Programs\スリープ防止ツール` に入る）
- デスクトップとスタートメニューにショートカットを作成
- 「設定 ＞ アプリ」にも登録されるので、そこからアンインストール可能

## 仕組み

| 対象 | 方法 |
|---|---|
| スリープ・画面OFF | `SetThreadExecutionState`（ES_SYSTEM_REQUIRED / ES_DISPLAY_REQUIRED） |
| スクリーンセーバー・自動ロック | 4分ごとに **F15キー**（どのアプリにも影響しない無害なキー）を送り無操作時間をリセット |

## 負荷（実測）

| | |
|---|---|
| メモリ | **約6MB**（旧PowerShell版は約60MB） |
| 待機中CPU | ほぼ0%（**OFFの間はタイマー自体を停止**） |
| exeサイズ | 9.5KB |

低負荷にするため、PowerShell+WinFormsをやめてC#でネイティブexe化し、
状態変化のたびに `SetProcessWorkingSetSize` でワーキングセットをOSへ返している。

## 注意

- **ONの間は会社ポリシーの自動ロック（10分・パスワード必須）が働きません。**
  席を離れるときは必ず OFF にするか `Win + L` で手動ロックしてください。
- AC電源時のスリープ/画面OFFは別途 `powercfg` で「なし」に設定済み（2026-08-14）。
  バッテリー駆動時は3分のままなので、電源を抜くときはこのツールが必要。

## ビルド方法

Windows標準のC#コンパイラを使う（Visual Studio不要）。

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /optimize+ ^
  /out:スリープ防止.exe /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll ^
  _作業ファイル\SleepGuard.cs
```

## 開発メモ（ハマったところ）

- **`.cs` は BOM付きUTF-8** で保存する。BOM無しだと csc が日本語リテラルを壊す。
- **`.bat` は Shift-JIS ＋ CRLF 改行** が必須。
  LF改行だと cmd が行を正しく分割できず、コマンドが混ざって壊れる（今回これで一度失敗した）。
- VBS/PowerShellを「非表示(SW_HIDE)」で起動すると、**最初に開くフォームもその指定を引き継いで非表示**になる。
  旧PowerShell版では `ShowWindow(handle, SW_SHOW)` を明示的に呼んで回避していた。
- `.bat` の `choice` は入力待ちで固まるので、`/t` と `/d` で既定値とタイムアウトを付けてある。
