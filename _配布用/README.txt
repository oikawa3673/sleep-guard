====================================================
 PCスリープガード  v1.0.0
====================================================

PCが勝手に スリープ / 画面OFF / スクリーンセーバー(自動ロック) に
なるのを、ONにしている間だけ抑止します。

長時間の処理・自動操作・デモ・説明中に画面が消えるのを防ぎます。


■ インストール

  「インストール.bat」をダブルクリックするだけです。
  （管理者権限は不要。自分のユーザー領域にのみインストールされます）

  デスクトップとスタートメニューに「PCスリープガード」が作成されます。


■ 使い方

  1. デスクトップの「PCスリープガード」を起動
  2. 「ON にする」をクリック → 緑色の ON になれば抑止中
  3. 終わったら「OFF にする」、またはウィンドウを閉じる

  ・最小化するとタスクトレイに入ります
    （アイコンをダブルクリックで再表示 / 右クリックでON-OFF切替・終了）
  ・トレイアイコンの色  灰色=OFF   緑=ON


■ 注意

  ONの間は自動ロックが働きません。
  席を離れるときは必ず OFF にするか、Win+L で手動ロックしてください。

  アプリを終了すれば抑止は自動的に解除されます。


■ アンインストール

  「設定 ＞ アプリ ＞ インストールされているアプリ」から
  「PCスリープガード」を選んでアンインストール

  または  アンインストール.bat  を実行


■ 動作環境

  Windows 10 / 11（.NET Framework 4.x = Windows標準で導入済み）
  追加のランタイム導入は不要です。

  メモリ使用量 約6MB / 待機中のCPU使用率 ほぼ0%
